# JAYA GROUP OF INSTITUTIONS — CENTRALIZED RESOURCE MANAGEMENT SYSTEM

A premier, authentic institutional web portal and centralized resource management platform designed for the **Jaya Group of Institutions** (under the aegis of Jaya Educational Trust, Estd. 1977, Thiruninravur, Chennai).

Designed with a **Premium Institutional Aesthetic** inspired by collegiate universities (Oxford, Harvard, Cambridge), combining deep navy blue, pure white, and muted gold accents with elegant serif headings and clean typography.

---

## 🏛️ OVERVIEW & ARCHITECTURE

The platform fulfills two complementary institutional mandates:
1. **Official University Group Portal:**
   - Public institutional identity, leadership directives, statutory recognitions (AICTE, Anna University, UGC, NAAC, NBA, PCI, NCTE).
   - Interactive editorial **Vertical Timeline Directory** chronicling the 9 constituent colleges and foundation school since 1977.
   - Dedicated Institution and Department pages showcasing academic divisions, curriculum, faculty strength, and research achievements.
   - Centers of Excellence, corporate placement statistics (92.4%+ rate, 120+ visiting recruiters), and campus life facilities.
   - Official university bulletins and Admissions 2026-2027 inquiry portal.

2. **Centralized Resource & Laboratory Management Platform:**
   - Multi-role role-based access control (System Administrator, Department Heads / HODs, Faculty, Lab In-Charges).
   - Dedicated laboratory, room, and bench management with hardware workstation allocation.
   - Institutional capital equipment inventory tracking (Asset tagging, serial numbers, operational status, valuation, maintenance workflows).
   - End-to-end resource requisition workflow (from faculty submission to administrative approval and asset dispatch).
   - Institutional audit reporting and printable board summary registers.

## 💻 LOCAL RUN & BUILD INSTRUCTIONS

### Prerequisites
- Node.js (v18+)
- npm (v9+)

### Installation
```bash
# Install dependencies
npm install
```

### Running Locally
```bash
# Start Vite development server
npm run dev
```

### Building for Production
```bash
# Production TypeScript check and Vite build
npm run build
```
